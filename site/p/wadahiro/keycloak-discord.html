✓What it can doできること3

  • Add "Log in with Discord" as a social identity provider.Discordログインをソーシャル Identity Provider として追加できる
  • Optionally allow federation only for members of specific Discord guilds (servers) by guild ID.ギルドIDを指定して、特定のDiscordサーバー（ギルド）のメンバーだけに連携を許可できる
  • No theme setup in the master realm is needed (since v0.3.0).v0.3.0以降、master realmでのテーマ設定は不要

✕What it cannot do / limitsできないこと・制約2

  • Only covers login/federation — the README documents no other Discord features (e.g. role or guild data mapping).機能はログイン/連携のみ。ロールやギルド情報のマッピングなど、それ以外のDiscord機能はREADMEに記載がない
  • Low activity — listed as "less active" on the official extensions page, with the last commit in 2024.活動は低調。公式拡張ページでは "less active" 扱いで、最終コミットは2024年

Requirements前提条件

  • A Discord application (client ID and secret) from the Discord Developer Portal.Discord Developer Portalで作成したアプリケーション（Client ID / Secret）
  • Deploy the JAR into $KEYCLOAK_HOME/providers.JARを $KEYCLOAK_HOME/providers に配置
