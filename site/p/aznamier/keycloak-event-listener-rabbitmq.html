✓What it can doできること3

  • Publish Keycloak user (client) and admin events as JSON to RabbitMQ (default exchange amq.topic).KeycloakのユーザーイベントとAdminイベントをJSONでRabbitMQへ送信（既定のexchangeは amq.topic）
  • Use structured routing keys (KK.EVENT.<type>.<realm>.<result>...) so consumers can subscribe by realm, client, result or event type with topic wildcards.構造化されたルーティングキー（KK.EVENT.<種別>.<realm>.<結果>...）で、realm・クライアント・成否・イベント種別ごとにトピックのワイルドカードで購読できる
  • Configure host, port, vhost, exchange, credentials and TLS (key/trust stores) through environment variables.ホスト・ポート・vhost・exchange・認証情報・TLS（キーストア/トラストストア）を環境変数で設定

✕What it cannot do / limitsできないこと・制約4

  • RabbitMQ only — no other brokers.RabbitMQ専用で、他のブローカーには送れない
  • Default credentials are admin/admin and TLS is off by default — set them explicitly.認証情報の既定は admin/admin、TLSは既定でオフ。明示的に設定が必要
  • The WildFly configuration options are deprecated (Keycloak 16 and older).WildFly向けの設定方法は非推奨（Keycloak 16以前）
  • No commits since March 2024 — inactive.2024年3月以降コミットがなく、活動停止状態

Requirements前提条件

  • Plugin 3.x needs Keycloak 16+; copy the JAR to /opt/keycloak/providers and enable the keycloak-to-rabbitmq event listener.プラグイン3.xはKeycloak 16以上が必要。JARを /opt/keycloak/providers に置き、イベントリスナー keycloak-to-rabbitmq を有効化
