✓What it can doできること2

  • Send a one-time code by SMS (through AWS SNS) as a second login factor.AWS SNS経由でSMSのワンタイムコードを送り、二要素目として使える
  • Serve as a reference implementation of a custom authenticator (explained in a blog post and videos).カスタムAuthenticator実装の参考になる（ブログと動画で解説あり）

✕What it cannot do / limitsできないこと・制約5

  • Not meant for production — the author says demo purposes only.本番利用は想定外（作者いわく「デモ用途のみ」）
  • No longer maintained, and the repository is archived.保守終了済みで、リポジトリはアーカイブされている
  • The author advises against SMS as a security factor ("convenience, no security").作者自身がSMSはセキュリティ要素として使うべきでないとしている（「利便性であってセキュリティではない」）
  • AWS SNS is the only SMS gateway.SMS送信手段はAWS SNSのみ
  • There is no real README; documentation is limited to the blog post and videos.まともなREADMEはなく、ドキュメントはブログと動画だけ

Requirements前提条件

  • An AWS account with SNS.AWS SNSを利用できるAWSアカウント
