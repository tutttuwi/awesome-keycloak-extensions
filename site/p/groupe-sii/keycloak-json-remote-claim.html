✓What it can doできること3

  • Add a protocol mapper that fetches a JSON value from a remote HTTP/REST endpoint and puts it into a token claim (any JSON type).外部のHTTP/REST APIからJSONを取得してトークンのクレームに入れるプロトコルマッパーを追加（JSONの型は問わない）
  • Optionally send the username and client ID, plus custom query parameters and HTTP headers.ユーザー名やクライアントIDの送信、任意のクエリパラメータやHTTPヘッダーの付与もできる
  • Make a single request when several tokens are issued in one response.1つのレスポンスで複数のトークンを発行する場合も、リクエストは1回で済む

✕What it cannot do / limitsできないこと・制約4

  • If the remote claim cannot be fetched, no token is issued (HTTP 500).外部からクレームを取得できないとトークンが発行されない（HTTP 500になる）
  • Built for Keycloak 8 on WildFly (standalone.xml modules) — not documented for Quarkus-based Keycloak.WildFly上のKeycloak 8向け（standalone.xml のモジュール登録）。Quarkus版Keycloakでの手順は記載がない
  • Uses the unofficial Protocol Mapper SPI.非公式扱いのProtocol Mapper SPIを使っている
  • The repository is archived, with no commits since 2020.リポジトリはアーカイブ済みで、2020年以降コミットがない

Requirements前提条件

  • Keycloak 4.6.0 or newer (WildFly distribution), with the module registered in standalone.xml.Keycloak 4.6.0以上（WildFly版）。standalone.xmlにモジュールを登録する
