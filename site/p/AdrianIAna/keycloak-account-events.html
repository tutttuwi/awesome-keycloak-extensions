✓What it can doできること4

  • Let users fetch their own login history (login, logout, login errors, …) with their own access token at /realms/{realm}/account-events/me — no admin credentials.ユーザーが自分のアクセストークンで、自分のログイン履歴（ログイン・ログアウト・ログインエラーなど）を /realms/{realm}/account-events/me から取得できる。管理者の認証情報は不要
  • Scope results strictly to the token's subject, with the same checks as Keycloak's account API (audience, roles, CORS, no service accounts).結果はトークンの本人分だけに限定され、Keycloakのアカウント APIと同じチェック（audience、ロール、CORS、サービスアカウントの拒否）を通る
  • Pass through custom event details — combined with keycloak-event-enrichment, each event carries location and device info.イベントの独自詳細もそのまま返す。keycloak-event-enrichmentと組み合わせれば、各イベントに位置と端末の情報が付く
  • Works even when the account console feature is disabled.アカウントコンソール機能を無効にしていても動く

✕What it cannot do / limitsできないこと・制約3

  • Returns an empty list unless user events are saved for the realm (off by default).realmでユーザーイベントの保存を有効にしないと、常に空のリストが返る（既定ではオフ）
  • No UI is included — it is an API for your own screens.UIは付属しない。自作画面のためのAPI
  • Requires Keycloak 26.6+ and uses an internal SPI (realm-restapi-extension), so a warning is logged and future versions may break it.Keycloak 26.6以上が必要。内部SPI（realm-restapi-extension）を使うため警告が出て、将来のバージョンで壊れる可能性もある

Requirements前提条件

  • Copy the JAR to /opt/keycloak/providers/, run kc.sh build, and enable "Save events" for LOGIN, LOGOUT and LOGIN_ERROR.JARを /opt/keycloak/providers/ に置いて kc.sh build し、LOGIN・LOGOUT・LOGIN_ERRORのイベント保存を有効化
