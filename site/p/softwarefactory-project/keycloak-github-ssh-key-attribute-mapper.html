✓What it can doできること2

  • Fetch a user's public SSH keys from GitHub when they log in with GitHub and store them in a user attribute.GitHubでログインしたときに、ユーザーのSSH公開鍵をGitHubから取得してユーザー属性に保存
  • Includes a Dockerfile, compose file and demo script.Dockerfile・compose・デモスクリプト付き

✕What it cannot do / limitsできないこと・制約3

  • You must alter the Keycloak database by hand (USER_ATTRIBUTE column size and index) to fit SSH keys.SSH鍵が入るように、KeycloakのDB（USER_ATTRIBUTEの列サイズとインデックス）を手作業で変更する必要がある
  • Only works with the GitHub identity provider.GitHubのIdPでしか動かない
  • Inactive — no commits since February 2024; versions before Keycloak 22 need a Java 11 rebuild.2024年2月以降コミットがなく活動停止状態。Keycloak 22より前はJava 11向けの再ビルドが必要

Requirements前提条件

  • A SQL database backend (example given for MariaDB/MySQL) and a GitHub OAuth app.SQLデータベース（MariaDB/MySQLでの例あり）と、GitHubのOAuthアプリ
