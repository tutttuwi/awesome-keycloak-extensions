✓What it can doできること3

  • Publish Keycloak events to an MQTT broker.KeycloakのイベントをMQTTブローカーへ送信
  • Configure broker, credentials (or anonymous), topic (default keycloak/events) and optional in-memory persistence.ブローカー、認証情報（匿名も可）、トピック（既定は keycloak/events）、メモリ上の永続化を設定できる
  • Ships a Dockerfile, compose file and demo script that set up Keycloak with an MQTT server.KeycloakとMQTTサーバーを立ち上げるDockerfile・compose・デモスクリプト付き

✕What it cannot do / limitsできないこと・制約3

  • MQTT only; the README does not describe filtering which events are published.MQTT専用。どのイベントを送るかの絞り込みはREADMEに記載がない
  • Tested on Keycloak 22; versions before 22 need a Java 11 rebuild.検証はKeycloak 22。22より前のバージョンではJava 11向けに再ビルドが必要
  • Inactive — no commits since May 2024.2024年5月以降コミットがなく、活動停止状態

Requirements前提条件

  • Copy the JAR to /opt/keycloak/providers, pass the MQTT settings as SPI options and enable the listener per realm.JARを /opt/keycloak/providers に置き、MQTTの設定をSPIオプションで渡して、realmごとにリスナーを有効化
