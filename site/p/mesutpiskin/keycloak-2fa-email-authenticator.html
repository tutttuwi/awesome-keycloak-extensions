✓What it can doできること4

  • Add an email one-time code as a second factor in browser flows.ブラウザフローに、メールのワンタイムコードによる二要素認証を追加
  • Configure code length, validity (TTL), resend cooldown and maximum attempts.コード桁数・有効期間（TTL）・再送の待ち時間・最大試行回数を設定できる
  • Send through Keycloak's SMTP, SendGrid, AWS SES or Mailgun.送信手段はKeycloakのSMTP、SendGrid、AWS SES、Mailgunから選べる
  • Optionally show a masked email address on the OTP form; templates can be customised.OTP入力画面でマスクしたメールアドレスを表示できる。テンプレートもカスタマイズ可能

✕What it cannot do / limitsできないこと・制約2

  • Email only — SMS, Telegram, WhatsApp and Signal are covered by a separate sibling project.メール専用。SMS・Telegram・WhatsApp・SignalはSibling project（別リポジトリ）の担当
  • Each release targets specific Keycloak versions — pick the -KC version that matches yours.リリースごとに対応Keycloakが決まっている。自分のバージョンに合う -KC 付きのバージョンを選ぶ

Requirements前提条件

  • A working mail backend (realm SMTP or one of the supported APIs).動作するメール送信手段（realmのSMTPか対応API）
  • The JAR from Maven Central matching your Keycloak version (see COMPATIBILITY.md).Keycloakのバージョンに合うMaven CentralのJAR（COMPATIBILITY.mdを参照）
