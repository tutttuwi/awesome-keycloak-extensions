✓What it can doできること3

  • Build a custom Keycloak distribution that includes Quarkus/Quarkiverse extensions (or other dependencies), the same way Keycloak itself is built.Quarkus/Quarkiverseの拡張（や他の依存関係）を組み込んだKeycloakディストリビューションを、Keycloak本体と同じ方法でビルドできる
  • Output tar.gz/zip distributions or a container image.成果物はtar.gz/zipのディストリビューションか、コンテナイメージ
  • Supports Keycloak 26.4.x, 26.6.x–26.8.x and nightly.Keycloak 26.4.x、26.6.x〜26.8.x、nightlyに対応

✕What it cannot do / limitsできないこと・制約2

  • Not a runtime extension — it is a build tool, so you run your own extended Keycloak build.実行時の拡張ではなくビルドツール。拡張したKeycloakを自前でビルドして運用する形になる
  • Only the listed Keycloak/Quarkus version pairs are supported.対応しているのは、表に記載されたKeycloakとQuarkusの組み合わせのみ

Requirements前提条件

  • A build environment for the tool (see the examples and advanced configuration guides).ツール用のビルド環境（examplesと詳細設定ガイドを参照）
