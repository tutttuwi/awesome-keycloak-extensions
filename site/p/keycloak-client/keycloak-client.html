✓What it can doできること3

  • Add OpenID Connect login to Python apps (login / callback).PythonアプリにOpenID Connectのログインを組み込める（login/callback）
  • Use UMA authorization — get a protection API token (PAT), create permission tickets and request RPTs.UMAの認可に対応。PAT（Protection API Token）の取得、パーミッションチケットの作成、RPTの要求ができる
  • Ships ready-made middlewares for Flask, Starlette and Django.Flask・Starlette・Django向けのミドルウェアが付属

✕What it cannot do / limitsできないこと・制約4

  • Not a Keycloak extension — a Python client library for apps that use Keycloak.Keycloak拡張ではなく、Keycloakを使うアプリ向けのPythonクライアントライブラリ
  • The documentation covers authentication and UMA authorization; Admin REST API management is not documented as a feature.ドキュメントの対象は認証とUMA認可。Admin REST APIによる管理機能は記載がない
  • Low activity — last commit at the end of 2024.活動は低調で、最終コミットは2024年末
  • Licensed under GPL-3.0, which has copyleft obligations when you distribute your app.ライセンスはGPL-3.0。アプリを配布する場合はコピーレフトの義務が生じる

Requirements前提条件

  • Python with pip install keycloak, and a Keycloak client configured for your app.Python環境で pip install keycloak。アプリ用のKeycloakクライアント設定も必要
