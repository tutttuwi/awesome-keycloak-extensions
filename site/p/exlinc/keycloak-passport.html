✓What it can doできること3

  • Use Keycloak as a Passport.js strategy (OAuth2/OIDC) in Node.js apps.Node.jsアプリで、KeycloakをPassport.jsのストラテジー（OAuth2/OIDC）として使える
  • Use several realms in the same application (multi-tenancy).1つのアプリで複数realmを扱える（マルチテナント）
  • Fetch the user's profile from Keycloak automatically.ユーザー情報をKeycloakから自動取得

✕What it cannot do / limitsできないこと・制約3

  • Not a Keycloak extension — a Node.js client library.Keycloak拡張ではなく、Node.js向けクライアントライブラリ
  • Known issues with recent next-auth versions.最近のnext-authとの組み合わせには既知の問題がある
  • Inactive — no commits since 2018, despite the README calling it maintained.READMEでは保守中とあるが、2018年以降コミットがなく活動停止状態

Requirements前提条件

  • Node.js with Passport.js, and an OIDC client in Keycloak.Passport.jsを使うNode.js環境と、Keycloak側のOIDCクライアント
