✓What it can doできること3

  • Show examples of adding custom domain entities, a custom event listener, a custom REST resource and a minimal custom theme.独自ドメインエンティティの追加、カスタムイベントリスナー、カスタムRESTリソース、最小限のカスタムテーマの実装例がある
  • Show how to override mail templates (with extra variables) and how to drop first/last-name validation on registration.メールテンプレートの上書き（変数追加）や、登録画面の姓名バリデーションを外す例もある
  • Ship a docker-compose demo with a sample realm, users and Mailhog.サンプルrealm・ユーザー・Mailhog付きのdocker-composeデモ環境がある

✕What it cannot do / limitsできないこと・制約3

  • No longer maintained (stated in the README; last commit 2022).保守終了（READMEに明記、最終コミットは2022年）
  • Built for the old WildFly-based Keycloak (/auth context path, keycloak.migration export) — not ready for current Quarkus versions without changes.旧WildFly版Keycloak向け（/auth パス、keycloak.migration によるエクスポート）。現行のQuarkus版では修正なしには動かない
  • Examples only, not production extensions.あくまで実装例で、本番用の拡張ではない

Requirements前提条件

  • Maven and Docker Compose to build and run the examples.ビルドと実行にはMavenとDocker Composeが必要
