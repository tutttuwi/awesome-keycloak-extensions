✓What it can doできること4

  • Make Keycloak compatible with Apple Platform Single Sign-on for macOS.KeycloakをApple Platform SSO（macOS）に対応させる
  • Accept requests only from enrolled macOS devices (device attestation), with a registration token for MDM verification.デバイス認証により、登録済みのmacOS端末からのリクエストだけを受け付ける。MDM確認用の登録トークンも使える
  • Let users and admins revoke registrations from the UI; manage devices through an API for MDM integration.ユーザーと管理者がUIから登録を取り消せる。端末はAPIで管理でき、MDMと連携可能
  • Releases are signed (SHA-256 checksum plus SSH signature) for verification.リリースには署名がある（SHA-256チェックサムとSSH署名）

✕What it cannot do / limitsできないこと・制約5

  • The client must be called psso (public, with the urn:apple:platformsso scope) — not configurable yet.クライアント名は psso 固定（public、urn:apple:platformsso スコープ付き）。まだ変更できない
  • "Revoke Refresh Token" must stay off, because the refresh token is used to log in.リフレッシュトークンをログインに使うため、「Revoke Refresh Token」はオフのままにする必要がある
  • There is no UI for managing devices — API only.端末を管理するUIはなく、APIのみ
  • Only PostgreSQL and MariaDB are supported as the Keycloak database.KeycloakのDBはPostgreSQLとMariaDBのみ対応
  • Licensed under GPL-2.0-or-later.ライセンスはGPL-2.0-or-later

Requirements前提条件

  • Keycloak 26.5+ with the declarative-ui feature enabled, and a macOS SSO extension on clients (e.g. the companion Weblogin SSO).declarative-ui 機能を有効にしたKeycloak 26.5以上と、クライアント側のmacOS SSO拡張（付属のWeblogin SSOなど）
