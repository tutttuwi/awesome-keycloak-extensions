✓What it can doできること2

  • Let Keycloak read secrets (e.g. IdP client secrets, SMTP passwords) from OpenBao or HashiCorp Vault's KV engine via the Vault SPI, instead of storing them in cleartext in the database.Vault SPIで、Keycloakが使う秘密情報（IdPのクライアントシークレット、SMTPパスワードなど）をOpenBao/HashiCorp VaultのKVエンジンから読む。DBに平文で保存せずに済む
  • Let realm admins manage those secret values through a Secrets Manager extension to the Admin REST API, without direct Vault access.Admin REST APIの拡張（Secrets Manager）で、realm管理者がVaultに直接触れずに秘密情報を管理できる

✕What it cannot do / limitsできないこと・制約2

  • Relies on Keycloak's internal vault and admin-realm-restapi-extension SPIs (and internal caching APIs), so a Keycloak update may break it; Keycloak logs warnings about this.Keycloakの内部SPI（vault、admin-realm-restapi-extension）と内部のキャッシュAPIに依存するため、Keycloakの更新で壊れる可能性がある。起動時に警告も出る
  • Supports the KV secrets engine only.対応はKVシークレットエンジンのみ

Requirements前提条件

  • A running OpenBao or HashiCorp Vault; see the deployment guide in the docs folder.稼働中のOpenBaoかHashiCorp Vault。導入手順はdocsのデプロイガイドを参照
