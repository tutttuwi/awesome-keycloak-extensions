✓What it can doできること2

  • Add authenticators that use IBM Security Verify for stronger authentication (including the IBM Verify mobile app) in Keycloak or Red Hat SSO.IBM Security Verify（IBM Verifyモバイルアプリを含む）を使った認証強化用のAuthenticatorを、KeycloakやRed Hat SSOに追加
  • Ships Docker-based scripts to build and run a Keycloak image with the extensions.拡張入りのKeycloakイメージをビルド・実行するDocker用スクリプトが付属

✕What it cannot do / limitsできないこと・制約3

  • Supports only Keycloak 10.0.1 and Red Hat SSO 7.4 (WildFly era) — not documented for current Keycloak.対応はKeycloak 10.0.1とRed Hat SSO 7.4（WildFly時代）のみで、現行Keycloakでの手順はない
  • Detailed usage is only in the user guide attached to each release, not in the README.詳しい使い方は各リリースに添付されたユーザーガイドにしかなく、READMEには載っていない
  • Inactive — no commits since 2020.2020年以降コミットがなく、活動停止状態

Requirements前提条件

  • An IBM Security Verify tenant; IBM JRE 1.8, Maven and Docker to build.IBM Security Verifyのテナント。ビルドにはIBM JRE 1.8・Maven・Docker
