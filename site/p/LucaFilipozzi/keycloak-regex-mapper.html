✓What it can doできること2

  • Map a multi-valued OIDC claim (e.g. groups) or SAML attribute (e.g. groupMembership) to many realm and client roles with one regex-based broker mapper.複数値のOIDCクレーム（groups など）やSAML属性（groupMembership など）を、正規表現ベースのブローカーマッパー1つで多数のrealm/クライアントロールにマッピング
  • Only manage roles flagged with a marker attribute, so locally assigned roles are left alone.マーカー属性を付けたロールだけを管理するので、管理者がローカルで付与したロールは影響を受けない

✕What it cannot do / limitsできないこと・制約3

  • Requires the upstream IdP to name groups after client IDs and role names, so the mapping is defined upstream.上流IdP側で、グループ名にクライアントIDやロール名を含める必要がある（マッピングは上流側で定義する形）
  • Deployed as an EAR into deployments (WildFly-era packaging).EARとして deployments に配置する（WildFly時代のパッケージ形式）
  • Inactive — no commits since 2021.2021年以降コミットがなく、活動停止状態

Requirements前提条件

  • Realm/client roles tagged with the configured attribute, and named regex groups (client, role) in the mapper configuration.設定した属性でタグ付けしたrealm/クライアントロールと、マッパー設定での名前付きグループ（client、role）
