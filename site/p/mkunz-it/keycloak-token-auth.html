✓What it can doできること3

  • Create a browser SSO session from an existing ID or access token passed via a pushed authorization request (PAR).プッシュ認可リクエスト（PAR）で渡したIDトークン/アクセストークンから、ブラウザのSSOセッションを作成できる
  • Fixes SSO for mobile apps that use the password grant or whose browser does not keep the session cookie.パスワードグラントを使っている、またはブラウザがセッションCookieを保持しないモバイルアプリでも、SSOが効くようになる
  • Ships a step-by-step secure setup (dedicated confidential proxy client with PKCE and forced PAR) and a test script.安全に使うための手順（PKCEとPAR必須の専用confidentialプロキシクライアント）とテスト用スクリプトが付属

✕What it cannot do / limitsできないこと・制約3

  • It deliberately bypasses one of Keycloak's security mechanisms — misconfiguration is risky, so follow the security considerations.Keycloakのセキュリティ機構の1つを意図的に迂回するため、設定を誤ると危険。セキュリティ上の注意事項に必ず従う
  • Needs a dedicated proxy client, custom browser flow and client scope; it is not a drop-in authenticator.専用のプロキシクライアント、カスタムのブラウザフロー、クライアントスコープが必要で、そのまま差し込むだけのAuthenticatorではない
  • Older packages on GitHub Packages may be removed without notice.GitHub Packagesの古いパッケージは予告なく削除されることがある

Requirements前提条件

  • Download the release JAR matching your Keycloak version and copy it to providers.Keycloakのバージョンに合うリリースのJARを providers に置く
