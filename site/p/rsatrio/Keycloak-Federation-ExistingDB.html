✓What it can doできること2

  • Let users log in with credentials from an existing database through any JDBC datasource (user federation).JDBCで接続できる既存DBの認証情報で、ユーザーがログインできる（ユーザーフェデレーション）
  • Configure the password lookup and user-data queries (by email) from the admin console.パスワード取得とユーザー情報取得のクエリ（メールで検索）を管理コンソールで設定できる

✕What it cannot do / limitsできないこと・制約4

  • Email is the only login name.ログイン名に使えるのはメールアドレスだけ
  • The user-data query may return only two columns (email and firstName).ユーザー情報のクエリが返せる列は2つ（emailとfirstName）だけ
  • Built and tested on WildFly-based Keycloak 11 with Java 8 (JNDI datasource) — not documented for current Keycloak.WildFly版Keycloak 11とJava 8（JNDIデータソース）でビルド・テストされたもので、現行Keycloak向けの手順はない
  • A simple example; inactive since 2023.シンプルな実装例で、2023年以降は更新がない

Requirements前提条件

  • A JDBC driver and datasource registered in Keycloak's WildFly server.KeycloakのWildFlyにJDBCドライバとデータソースを登録しておく
