✓What it can doできること4

  • Email users when a new Keycloak session is created, with login time, IP address, client ID and User-Agent.新しいKeycloakセッションが作られたときに、ログイン時刻・IPアドレス・クライアントID・User-Agentを記載したセキュリティ通知メールを送る
  • Send at most one email per session (deduplicated across SSO clients and token refreshes).1セッションにつき1通だけ送る（SSOでの別クライアントやトークン更新では重複しない）
  • Change subject and wording per realm and language in the Admin Console, and optionally add buttons to the sessions or password pages.件名や本文は、realmと言語ごとに管理コンソールから変更できる。セッション画面やパスワード変更画面へのボタンも追加できる
  • Includes a guarded deployment for the Univention Keycloak App.Univention Keycloak App向けの安全なデプロイ手順が付属

✕What it cannot do / limitsできないこと・制約4

  • No geographic location is included (no GeoIP).位置情報は含まれない（GeoIPは使わない）
  • Users without an email address are skipped; IPs are only accurate with correct reverse-proxy settings.メールアドレスのないユーザーには送られない。IPアドレスはリバースプロキシの設定が正しい場合にのみ正確
  • Emails are sent synchronously during the login, so SMTP timeouts must be kept short (failures do not block login).メールはログイン処理中に同期で送られるため、SMTPのタイムアウトは短くしておく必要がある（失敗してもログインは止まらない）
  • Built against Keycloak 26.7.0; other versions need a rebuild because provider APIs are version-coupled.Keycloak 26.7.0向けにビルドされている。プロバイダーAPIはバージョンに依存するため、他のバージョンでは再ビルドが必要

Requirements前提条件

  • Working realm SMTP, the login-notification email theme, and the login-notification event listener.realmのSMTP設定、メールテーマ login-notification、イベントリスナー login-notification の有効化
